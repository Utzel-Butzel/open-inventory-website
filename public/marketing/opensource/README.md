# Open Source Initiative logo

Official, unmodified horizontal OSI logo with registration mark, downloaded 2026-10-31.

- Source: https://opensource.org/wp-content/uploads/2023/01/OSI_Horizontal_Logo_0.png
- Brand guidance: https://opensource.org/about/brand-and-trademark-guidelines
- Local file: `osi-horizontal.png` (1488 × 720, PNG)

The logo is a trademark of the Open Source Initiative, not an Open Inventory asset covered by the project's MIT license. It links to opensource.org. A white backing preserves the original colours and legibility in both themes. The shared footer includes attribution and states the absence of affiliation or endorsement.

The site is still a local preview. OSI's guidance asks community sites to provide a copy of the use via its contact form when using the mark. No message has been sent on the user's behalf.
