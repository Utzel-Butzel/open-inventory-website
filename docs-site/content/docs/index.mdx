## Start with your instance

New to self-hosting? Use the [simple setup guide](https://openinventory.polyxo.de/docs). For a terminal-based installation, follow the [Docker guide](/installation).

Once your instance is running, configure [sign-in and access](/authentication), try a [test label](/printing) or connect an external tool through the [API](/api).

## Open source, on your server

Open Inventory runs on your infrastructure. This documentation site stores no inventory data; API requests go to your own instance.

Find the source code, report an issue or contribute on [GitHub](https://github.com/Utzel-Butzel/inventory).
