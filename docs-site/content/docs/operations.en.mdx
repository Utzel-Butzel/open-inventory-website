---
title: "Operations and backups"
---

- Back up the database and uploaded files together, and test restoring them.

- Configure HTTPS and keep database access on the internal network.

- After updates, check /api/health, sign-in and uploads. Migrations run at production startup.

- Maintain the shared printer’s Windows agent and protected configuration. Preserve pending.json during updates to avoid losing recovery information for uncertain jobs.
