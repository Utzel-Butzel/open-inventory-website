Wähle einen Bereich oder suche nach einem Endpunkt. Die Referenz wird aus der OpenAPI-Spezifikation der Anwendung erzeugt. Feldnamen und technische Schemabeschreibungen bleiben in ihrer englischen Originalfassung.

Ersetze `https://inventory.example.com/api/v1` durch die Adresse deiner eigenen Instanz. [Authentifizierung und erster Request](/de/api) erklären die unterschiedlichen Token und Berechtigungen. Aufrufe mit einer Browsersitzung testest du auf der Anwendungsinstanz; für Requests von einer anderen Domain gelten deren CORS-Regeln.
