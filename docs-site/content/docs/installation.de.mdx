---
title: "Mit Docker starten"
---

Du brauchst Git, Docker Compose v2, OpenSSL und curl. Der Installer startet die Anwendung und PostgreSQL mit persistenten Volumes und führt die Datenbankmigrationen aus.


```bash
git clone https://github.com/Utzel-Butzel/inventory.git
cd inventory
./scripts/install.sh
```

Der Installer erstellt die .env und erzeugt die nötigen Geheimnisse. Am Ende zeigt er die Adresse und den ersten Admin-Zugang an, standardmäßig admin@inventory.local. Melde dich mit dem ausgegebenen Passwort an und ändere es unter Einstellungen → Benutzer.

Für Dokploy und Coolify stehen eigene Deployment-Vorlagen bereit. Sie richten Datenbank, Upload-Speicher und Healthcheck ein. Das erste Passwort findest du dort in den Umgebungsvariablen der Plattform.
