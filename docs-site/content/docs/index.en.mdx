Getting started for the first time? Follow the [simple Dokploy or Coolify setup guide](https://openinventory.polyxo.de/docs) through to your first item.

Use these guides for more detailed configuration:

- [Docker installation](/en/installation): install from a terminal.
- [Configuration](/en/configuration): your address, file storage, AI and maps.
- [Sign-in and access](/en/authentication): local users, Auth0 and OpenID Connect.
- [Labels and printing](/en/printing): browser printing, QZ Tray and shared printers.
- [Stock planning and counting](/en/planning): forecasting, bills of materials and quantity estimates.
- [Variants and assembly](/en/variant-stock): build, attribute and issue stock.
- [Operations and backups](/en/operations): updates, backups and recovery.

## Connect your own systems

Start with the [API quick start](/en/api). The [API reference](/en/api-reference) describes every documented endpoint, parameter and response.

This documentation site stores no inventory data. API requests go to your own Open Inventory instance.
